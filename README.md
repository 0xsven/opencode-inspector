# OpenCode Inspector

A local dashboard for exploring your OpenCode usage and browsing your configuration. It doesn’t modify your OpenCode history or settings.

## Get started

You’ll need Git, Node.js 24, and OpenCode.

```sh
git clone https://github.com/0xsven/opencode-inspector.git
cd opencode-inspector
npm ci
npm run build
npm start
```

Open [http://127.0.0.1:4317](http://127.0.0.1:4317). Your usage may take a moment to appear while Inspector builds its first index.
